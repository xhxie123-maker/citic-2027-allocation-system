# 中信 2027 策略 · 投资决策系统

把**中信证券研究部 2027 年 A 股 / 港股投资策略**，转成一套「评分 → 仓位 → 标的 → 调仓 → 复盘」的可执行决策系统。

打开即用，纯静态页面，无需后端、不上传任何数据：所有计算在浏览器本地完成。

**线上地址（GitHub Pages）**：<https://xhxie123-maker.github.io/citic-2027-allocation-system/>

> 基线：中信证券研究部《A股市场2027年投资策略：调整前置，转机将现》《港股市场2027年投资策略：风险已充分计价，修复行情有望开启》及 2027 年资本市场策略会公开要点（2026 年 11 月）。
> **本系统是策略框架工具，不构成投资建议，也不构成收益承诺。**

---

## 一、它解决什么问题

研报给的是「判断」，不是「仓位」。从「K 型收敛、稳健回报占优」到「今天该买多少、买哪一类、什么时候减」，中间缺三层翻译：

1. **判断 → 分数**：把研报的宏观/风格/估值/流动性判断变成可量化、可复盘的六个维度打分；
2. **分数 → 仓位**：分数只决定权益中枢，不决定行业；结构由研报四条主线与可观测信号决定；
3. **仓位 → 动作**：输出到子类的权重与金额、调仓单、止盈止损与时间止盈，最后落成一条条纪律。

这三层在本系统里分别对应「决策引擎」「信号雷达」「配置与调仓」「纪律与风控」。

## 二、六个模块

| 模块 | 做什么 |
|---|---|
| **总览** | 研报三条核心判断、四条主线、当前结构、信号状态、下一步动作 |
| **决策引擎** | 六维打分（盈利动能 / 估值分位 / 行情宽度 / 流动性与资金 / AI 产业周期 / 风险事件），输出评分、仓位系数、权益中枢 |
| **信号雷达** | 研报列示的 6 个切换信号，只允许「已触发 / 未触发」两态，触发即改写结构权重 |
| **配置与调仓** | 目标权重与金额、标的池（按指数，不锁代码）、当前市值录入、偏离与买卖建议、导出调仓单 CSV |
| **纪律与风控** | 资金时间轴（建仓 / 持有 / 减仓 / 到期）、纪律条款、情景压力测试、红线、首月清单、决策日志 |
| **研报溯源** | 三份研报出处、参数映射表、以及「研报没给、系统也不假装有」的边界说明 |

## 三、决策模型

### 1. 评分

```
综合评分 S = Σ ( 维度权重 × 维度得分 )          // 0—100，50 为中性
```

| 维度 | 权重 | 输入 | 打分函数 |
|---|---|---|---|
| 盈利动能 | 20% | 全 A 归母净利同比 | `50 + (增速 − 9.5%) × 8`（9.5% 为研报 2027E 基准） |
| 估值分位 | 20% | 沪深 300 PE 历史分位 | `50 + (50 − 分位) × 1.2` |
| 行情宽度 | 18% | 非 AI 相对 AI 的修复强度 0—100 | 直接取值（研报主线：K 型收敛、宽度拓展） |
| 流动性与资金 | 17% | 降息 / 南向 / 国内流动性 | `50 + 26×降息 + 15×南向 + 9×国内` |
| AI 产业周期 | 15% | 算力资本开支同比 | `50 + (增速 − 20%) × 2` |
| 风险事件 | 10% | 研报风险清单发酵程度 | 90 / 72 / 50 / 20 四档 |

> 权重与打分函数是本系统的**工程设定**，不是研报给定的数值；研报给定的是方向与基准（如 2027E +9.5%、恒生科技 PE 2.4% 分位）。改 `assets/data.js` 即可整体替换。

### 2. 仓位

```
仓位系数 = clamp(1 + (S − 50) / 50 × 0.35, 0.60, 1.35)
权益中枢 = clamp(档位权益 × 仓位系数, 25%, 95%)
小额档另封顶 90%（锁定 10% 缓冲）
```

档位权益（研报三档 + 一个精简档）：

| 档位 | 底仓 | 卫星 | 港股 | 缓冲 | 适用 |
|---|---|---|---|---|---|
| 防御型 | 65 | 15 | 8 | 12 | 回撤 <10%，3 年内可能用钱 |
| **稳健型（研报主模板）** | **55** | **30** | **10** | **5** | 3—5 年闲钱，可承受 15%—20% 回撤 |
| 进取型 | 45 | 40 | 12 | 3 | 5 年以上，可承受 25%+ |
| 小额精简（<1 万 · ≤1 年） | 70 | 20 | 0 | 10 | 金额小、期限短，只持 3—4 只 |

### 3. 结构倾斜（研报 → 权重）

| 输入 | 影响 |
|---|---|
| 行情宽度↑ | 宽基 +（最多 +10pp），红利 / 自由现金流 − |
| AI 资本开支↑ | AI 硬件 +，内需修复 − |
| 财政加力信号 | 内需修复 +10pp（由 AI、制造各让 5pp） |
| 美联储降息 / 南向加速 | 港股成长 +（最多 +30pp） |
| 港股解禁压力 | 港股成长 −15pp，维持红利压舱 |
| 地缘 / 中美摩擦 | 港股成长 −15pp、AI −8pp、黄金 +10pp |

**单赛道硬上限 15%**：任一行业主题超过研报的「不押单一赛道」上限即自动压回，超出部分转给同层其余子类。

### 4. 情景与时间

- 情景压力测试：权益 +25% / +4% / −18%，按当前权益中枢与缓冲层加权，输出组合收益与期末金额（假设值，非预测）。
- 时间轴：0—3 月建仓，3—(N−1) 月持有，(N−1)—N 月减仓，满 N 月到期清零。

## 五、使用

1. 直接打开页面（或访问 GitHub Pages 地址）；
2. 在「决策引擎」选档位、填本金与期限，按周/月更新六维输入与估值锚；
3. 在「信号雷达」只对**已发生**的事件点「已触发」；
4. 在「配置与调仓」录入当前市值，导出调仓单，按偏离执行；
5. 每次调整后「记入决策日志」，季度再平衡时回看。

输入与日志仅存本机浏览器（`localStorage`），换设备不同步。

本地自测：`node tests/engine.test.js`，校验各档位与极端输入下的不变量——权重与金额合计 100%、单赛道 ≤15%、无 NaN。

## 六、已知边界

- 研报未给出精确组合权重、个基名单与择时点位：档位比例属派生模板，标的只给指数与类型，**不锁代码**（代码、规模、费率、溢价率请在下单前核对）。
- 六大维度权重、打分函数、情景收益均为工程设定，可被替换，不代表中信原值。
- 无实时行情接口：本系统不做数据抓取，避免行情源失效导致的错误决策；输入由使用者按券商 / 终端数据填写。
- 研报观点有有效期。若中信发布 2027 年中期策略或调整盈利预测，应更新 `assets/data.js` 的 `params` 与默认输入，并在决策日志里记录版本变更。
